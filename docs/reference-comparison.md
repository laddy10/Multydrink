## Diferencias y pendientes explícitos

Las tres cifras científicas son años: adaptación necesaria para conservar la composición sin inventar resultados. Memoria explica los límites de evidencia en vez de prometer mejoras. La etiqueta declara 0,2 g de azúcares añadidos; nunca se anuncia cero.

La galería inicia con el pack real de seis cajas. La composición botánica se identifica como imagen de marca. No se usa el pack como supuesta foto individual. Caja/Sobres controla imágenes, no ofertas.

El usuario confirmó que los recursos de ChatGPT aún no están en el proyecto. [Inventario requerido](../assets/README.md). No se inventaron, descargaron ni generaron reemplazos durante esta fase. La fidelidad visual seguirá pendiente hasta integrar los archivos y comparar ambas páginas a 1440, 768/1024, 390 y 320 px.
